# Kundan Kumar Premium Portfolio

A responsive, animated portfolio website for internship applications.

## Features
- 3D hero card
- Particle background
- Typing animation
- Glassmorphism design
- Dark / light mode
- Project filtering
- Contact form UI
- AI portfolio assistant
- Visitor counter using localStorage
- SEO meta tags
- Mobile responsive layout

## How to run
1. Open this folder in VS Code
2. Open `index.html`
3. Right click > Open with Live Server

## Customize
- Replace `resume.pdf` with your real resume PDF
- Update projects in `index.html`
- Update GitHub/LinkedIn links if needed
- Add real certificate images later
